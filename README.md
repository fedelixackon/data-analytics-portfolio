1. Online Customer Purchase Prediction

Tools: R, Machine Learning, Statistical Analysis

Analyzed 12,330 e-commerce sessions to identify purchasing patterns.

Compared six classification models, including Logistic Regression, LDA, QDA, Naive Bayes, KNN, and Random Forest.

Selected Random Forest, achieving 89.9% test accuracy and 92.24% ROC-AUC.

Key Skills: Data Analysis, Predictive Modeling, Model Evaluation, Data Visualization.
